## Storage and index calculation

`flag_helpers.asm` defines `eventFlags` at `$0A00` and `wramFlags` at `$0A80`. The ordinary scene-flag COP handlers call the event-flag helper family; the separate dungeon-kill handler uses WRAM flags. Do not combine these spaces.

For an event flag index `n`, the helper selects byte `$0A00 + (n >> 3)`, bit `n & 7`, and mask `1 << (n & 7)`. Byte and word COP operations are operand-width variants over the same event-flag bitfield; they do not identify separate storage pools. The index table below reports only literal COP operands and calculates their event-array location using this formula.

`TestEventFlag` and `TestWramFlag` return presence through carry. The COP `BranchOnFlag*` and `WaitOnFlag*` operations test flags; `SetFlag*` sets event flags and `ClearFlag*` clears them. See the linked handler/helper source for implementation details.
