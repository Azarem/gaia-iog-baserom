## 1. Answers

**What is D7?** Two things in one range. (a) `$0500-$0507`: byte `$0AA0`, the "boss reward taken" bits, reached only through `TestWramFlag_Offset100` / `SetWramFlag_Offset100` (index AND 7, base `$0100` on `wramFlags` `$0A80`). (b) `$0510-$051F`: the 16 bits of the word `$0AA2-$0AA3`, which is also `abilityBitmask`; flag `$0510 + characterForm*4 + slot` (`TestFlag_0510`, adds `$0510`). Grade VERIFIED-STATIC. Everything else the shipped D7 range covered (`$0508-$050F` = `$0AA1`, `$0520-$059F` = `$0AA4-$0AB3`) is not flag storage (section 4, `_no_use` rows).

**Lifetime.** Both bytes are in the save block `$0A00-$0BFB` (FL10). `ClearSceneState` (`$0A00-$0A01`), `ClearAllWramFlags` (`WorldMapController.asm:105` `{238336}`, `st68_kara.asm:96` `{438261}`, `sp58_red_eye.asm:68` `{426502}`; loop `STA $L_wramFlags, X` `{46291}`, `CPX #$0020`) and the inline loop of `game_over_sequence.asm:141` `{54994}` all cover `$0A80-$0A9F` only, one byte below `$0AA0`. A set bit therefore survives scene changes, the world map and a game over. Boot zero-fills WRAM, `SystemInit` stores 0 to the low byte of `abilityBitmask` (`system_core.asm:219` `{32946}`, 8-bit `STA`), `DiaryNewGameStart` writes neither byte (FL10).
