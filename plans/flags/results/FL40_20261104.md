## 1. Facts that shape everything below

- Items, form, gems, abilities and the counters are **not** flag-bitfield state. They live in the same 508-byte block `$0A00-$0BFB` that is saved and loaded, so a preset must write them as bytes.
- `inventorySlots` `$0AB4-$0AC3`: 16 bytes, item id each, 0 = empty. `inventoryEquippedIndex` `$0AC4` = slot index, `$FFFF` = none. `inventoryEquippedType` `$0AC6`. `GiveItemToPlayer` (`inventory_mgmt.asm`) id encoding: `$00-$7F` stores the id in the first empty slot (full: returns the overflow); `$80` max HP + 1, `$81` STR + 1, `$82` DEF + 1, `$83/$84/$85` gems + 1/+2/+5 (cap 999), `$86+` heal 5 HP with sparkle. COP handlers: `GiveItem` #D4 (operand: id, overflow `&Code`), `RemoveItem` #D5, `BranchIfHasItem` #D6, `BranchIfItemEquipped` #D7. Besides the COP there are 10 `JSL GiveItemToPlayer` call sites in 5 files: `pyCD_puzzle` x6 (constant plate ids, {576546} {576573} {576597} {576621} {576645} {576669}), `item_use_system` {236373} (plate swap), `warps_interaction` {173862} (chests, id from `scene_chest_table`), `cop_handlers_inventory` {44045} (the `GiveItem` COP itself) and `combat_collision` {247010} (`InteractionDamage_NPCChat`: the pickup actors carry the item id in `chatPtr` `$7F000A`; the ids that reach it are `$80-$86`: `EnemyDropSystem` `$83-$86` {57144} {57185} {57289} {57315}, `field_reveal_object` `$80-$85`, `idle_sprite_display` `$85` {589058}).
- `characterForm` `$0AD4`: 0 Will, 1 Freedan, 2 Shadow. The only form-test COP, `BranchIfBodyNe` (COP #49, `cop_handlers_actor_query.asm:206`), has no user in extracted code (search: every `COP [BranchIfBodyNe]` under `extracted/`: 0 hits). Every form gate is therefore a direct `LDA $characterForm`.
- `SwitchCase` (COP #D9, `cop_handlers_dungeon_switch.asm`) reads the BYTE at the absolute WRAM operand and indexes a word table; there is no bounds check. `#$0000` reads scratch `$0000` that the script loaded with `LDA addr; STA $0000` just before. Non-`$0000` operands: `$0AD4` in `thinkers/global_ambient_dispatcher.asm:45 {49035}` (palette by form at spawn); `$0AA6` in `gold_ship/adrift/dc2F_adrift.asm` (7-entry stage list, offset 366354); `$0004` in `smooth_follow` {59585} (actor DP, not state).
- A load always resumes in Dark Space scene `$E6` with `globalScriptIndex` restored from `$0AB2` (the saved layout variant). `$0B06` (saved `sceneCurrent`) has no reader (section 5).
- Item and form checks are scene-independent except where the script tests `sceneCurrent` first. Flag scratch `$00-$0F` is cleared at every scene load: the use-handler handshakes of section 7 work only inside one scene.
