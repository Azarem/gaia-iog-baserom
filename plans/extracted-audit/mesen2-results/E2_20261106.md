## Script

Verbatim in [E2_20261106_lua.md](E2_20261106_lua.md): the kit calls and every targeted scenario. The kit (`kit/lib/e2_palette.lua`) hooks exec on `PaletteRestart` 37729, `PaletteStart` 37732, `PaletteStartLoop` 37761, the `PaletteStep` end exits 37816 and 37865 and `LoadPaletteBundle` 254128. A start row logs bundle id, scene, frame, `$36` delta, op, return site and slot; the first two ends log observed ticks; a capture row holds CGRAM before / first staged frame / last staged frame / CGRAM after.

## Positive control

Every run: write callback on `$36` (INC $36 in the NMI) and exec callback on the NMI entry. Sweep chunks: `$36` writes 4,930 and NMI hits 4,902 in a 29-scene chunk (4,186 / 4,162 in the last chunk); the difference is one NMI hit per state load (the first NMI after a load is not seen). The control fired in all 8 chunks and in every targeted run. The sweep was run twice (the second time with one R1 dump per chunk): the 8 result files are byte-identical (SHA-1), so runs are deterministic.
