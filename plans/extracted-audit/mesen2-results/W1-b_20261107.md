## Static prelude

Method: `rg` of every operand that names a watched byte in `extracted/` (by address and by name: `mapTilemapBaseB`, `scrollOverrideH`, `forcedScrollOverride`, `scrollOverrideV`, `layerPriorityFlag`, `scrollModeFlags`, `playerSpriteCachePtr`, `playerSpriteCacheBank`, `$06F0`, `$06F2`, `$0402`, `$0404`, `$0405`, `$0D6E`), tagged with the ROM offset of the instruction (`; {n}`), the routine being the nearest label above plus the byte offset. The full table with runtime counts is in `raw/W1b_report.md` ("Static census"); the compact form below lists every static site and its run-time count (x0 = the site never ran in the 89,656 + 15,602 frames). Word accesses cover two bytes: `LDA $06EF` (16-bit) also reads `$06F0`, `LDA $06C7,X` reads the flag byte of layer X.

Findings that shaped the instruments:

- `$06A0` (`mapTilemapBaseB`) has one writer, `wram-init $06A0, #$C000` at `InitSystemVariables+54` (system_init.asm:206 / 171642), and readers in `StoreMapAndDecompress` and the tile strip renderers; `FillCollisionFromLayer1` (scene_script.asm:2165, offset 168056) reads the word `$0080` instead. Probe: `$0080` at 168056.
- `$06C8` (`forcedScrollOverride`) is written by `Layer1DriftUnbounded+85` (layer1_scroll_actors.asm:95), `Layer1ParallaxRatio` (127, 143, 158), `ScrollCameraInit+55` (camera_scroll.asm:65) and zeroed by `ClearSceneState+39` / `OpenInventoryScreen+198`. The static `rg` found no named reader, but `WriteBgScroll` (system_core.asm:681) reads `scrollOverrideH, X` (offset 33753) with the flag in bit 7 of `$06C7+X`: for X = 2 the value byte is `$06C8` and the flag `$06C9`. `$06CC` is the BG2 slot of the vertical pair (`scrollOverrideV` = `$06CA`, flag `$06CB+X`).
- `$06EF` is the high byte of the word `layerPriorityFlag` (`$06EE`) and `scrollModeFlags`; the only static store is `SceneCmd_ConfigDisplay+219` (scene_script.asm:1263, offset 166728), whose source is the low 5 bits of display preset record byte +7. Presets `$19 / $2A / $2B / $2D` have bit 4 set and belong to scenes `$59`, `$8C`-`$8F`, `$C0`, `$FE` (the warp targets of `warp_b`).
- `$06F0`/`$06F1`: the reader `ORA $06F0` is `InitActorFromSceneData+41` (actor_execution.asm:965); the writer is `STA $06F1` in `SceneCmd_ConfigDisplay+62` (scene_script.asm:1178, offset 166571), found by the 16-bit overlap with the word.
- `$06F2`: writers `SpcMusicLoadCmd+3`, `UseItem_MemoryMelody+84`, `pyCD_flame_statue2+397`; readers `SpcMusicLoadCmd+108`, `ChestOpeningActor`, `MusicJingleActor`, `FluteMusicActorController+6`.
- `$0402-$0405`: the RAM stub (`PHB / MVN / PLB / RTS`) and its operands `$0404` (destination bank) / `$0405` (source bank) are written by `CopyPalette`, `DmaRomToWram`, `LoadScenePalettes`, `CopyPaletteBundleFrame`, `GlobalAmbientTalk*`, `DiaryCopyExecute` and `InitSystemVariables`. `LoadPlayerGraphics` (scene_lifecycle.asm:1130) does not use the stub: it uses `DmaWordToVram` and skips scenes `$F7 / $FE / $8C` by `CMP`.
- `$0D6E/$0D6F`: writers `ExecuteSceneTransition` (normal path: `$0D6E` := `sceneCurrent`; world-map entry path: `$0D6E` := `sceneNext`, `$0D6F` := `sceneCurrent`) and `DeferSceneTransition+10` (WorldMapController.asm:136); readers `DisplaySceneTitle`, `TiltPhaseStart`, `SkipToSceneTransition`, `RouteTrulyEnded+6`, `RouteEndLanding+27`.
- `$09CC/$09CE` are `playerSpriteCachePtr` / `playerSpriteCacheBank` (names exist): `CheckPlayerSpriteCache`, `DecomposePlayerSprites`; cleared by `ClearSceneState+90/+93` and `OpenInventoryScreen+407/+410`.
- Flag `$FF` = byte `$0A1F` bit 7: `SetFlagByte #FF` at scene_lifecycle.asm:886 (253564); the byte is read by `TestEventFlag+23` (flag_helpers.asm:160) with `A` = bit mask (`$80`), by `SetEventFlag`, and cleared by `ClearSceneState+148/+153`.

Kit `kit/lib/w1b_kit.lua` (verbatim; the options `extraProbes`, `ctxMask` and the probe field `dp` were added after the 46 main runs; the main runs do not set `extraWatch` / `extraProbes` / `ctxMask` / `dp`, only the 11 follow-up runs do, so their behaviour is the same):

```lua
-- description: W1 address census (batch b: scene and flags) with per-scene tally, read values, last-writer pairing, exec marks and value probes.
-- requires: mesen_kit, iog_kit, gaia_kit
--
-- Use:  includes = {"gaia_kit", "a_census", "w1b_kit"}   then   local h = w1b.startB{logCap=60}   and   acen.run{..., final=function() return h.rows() end}
--
-- Every hit is keyed "<watch name> <read|write> <K:PC>" (PC = the address AFTER the accessing instruction; the harness maps it to the
-- instruction that ENDS there). Per key: count, first/last frame, first scene, per-scene counts, per-address counts, the distinct values
-- (max 8; the byte written, or for a read the byte read), and for watches with ctx=true the actor context of the access (direct page D = the slot
-- address inside a COP handler, and the slot's entry word and bank byte). Reads are paired with the K:PC of the last write seen on the same
-- byte ("init" = no write seen yet). A `bits` entry (write only) records a write only when it changes a bit of the mask (old ~ new): the
-- bit-change variant of plan 6.1.
-- Exec marks (snesPrgRom offsets; alias-proof) count executions and the scenes. Probes read a WRAM value at each execution of an instruction
-- (the callback runs before the instruction) and tally the distinct values with the scene.
w1b = w1b or {}

local WR = emu.memType.snesWorkRam

function w1b.start(opts)
  local self = { keys = {}, pairsT = {}, lw = {}, ctl36 = 0, nmi = 0, frames = 0, scenes = {}, sceneSeq = {}, execs = {}, probes = {}, logN = 0, hits = 0 }
  local LOGCAP = opts.logCap or 120
  local lastScene = nil

  local function hit(w, kind, a, v)
    local off = kit.wramOffset(a) or (a & 0xFFFF)
    if w.bits and kind == "write" then
      local old = kit.r8(off)
      if ((old ~ v) & w.bits) == 0 then return end
    end
    local st = emu.getState()
    local k, pc, f = st["cpu.k"], st["cpu.pc"], st["frameCount"]
    local sc = kit.r16(0x0644)
    local pck = string.format("%02X:%04X", k, pc)
    local key = w.name .. " " .. kind .. " " .. pck
    local e = self.keys[key]
    if not e then
      e = { name = w.name, kind = kind, pc = pck, n = 0, first = f, scene0 = sc, scenes = {}, addrs = {}, vals = {}, nv = 0, ctx = {}, nctx = 0 }
      self.keys[key] = e
      if self.logN < LOGCAP then
        self.logN = self.logN + 1
        gaia.log("%s f=%d sc=%02X a=%04X v=%02X D=%04X", key, f, sc, off, v, st["cpu.d"] or 0)
      end
    end
    self.hits = self.hits + 1
    e.n, e.last = e.n + 1, f
    e.scenes[sc] = (e.scenes[sc] or 0) + 1
    e.addrs[off] = (e.addrs[off] or 0) + 1
    if e.vals[v] or e.nv < 8 then
      if not e.vals[v] then e.nv = e.nv + 1 end
      e.vals[v] = (e.vals[v] or 0) + 1
    end
    if w.ctxMask then
      -- read callbacks run before the instruction executes: for `AND $eventFlags, Y` in TestEventFlag A still holds the bit mask ($80 = flag $FF)
      local d = st["cpu.d"] or 0
      local ck = string.format("a%02X:D%04X:ent%04X", (st["cpu.a"] or 0) & 0xFF, d, (d >= 0x1000 and d <= 0x1FBF) and kit.r16(d) or 0)
      if e.ctx[ck] or e.nctx < 40 then
        if not e.ctx[ck] then e.nctx = e.nctx + 1 end
        e.ctx[ck] = (e.ctx[ck] or 0) + 1
      end
    elseif w.ctx then
      local d = st["cpu.d"] or 0
      if d >= 0x1000 and d <= 0x1FBF then
        local ck = string.format("D%04X:ent%04X:b%02X", d, kit.r16(d), kit.r8(d + 2))
        if e.ctx[ck] or e.nctx < 12 then
          if not e.ctx[ck] then e.nctx = e.nctx + 1 end
          e.ctx[ck] = (e.ctx[ck] or 0) + 1
        end
      end
    end
    if kind == "write" then
      self.lw[off] = pck
    else
      local pk = key .. " <- " .. (self.lw[off] or "init")
      local p = self.pairsT[pk]
      if not p then p = { key = pk, n = 0, first = f, scene0 = sc, addrs = {} }; self.pairsT[pk] = p end
      p.n, p.last = p.n + 1, f
      p.addrs[off] = (p.addrs[off] or 0) + 1
    end
  end

  for _, w in ipairs(opts.watch or {}) do
    for _, kind in ipairs(w.kinds or { "read", "write" }) do
      emu.addMemoryCallback(function(a, v) hit(w, kind, a, v) end, emu.callbackType[kind], w.lo, w.hi, emu.cpuType.snes, WR)
    end
  end

  for name, off in pairs(opts.exec or {}) do
    local e = { n = 0, off = off, scenes = {} }
    self.execs[name] = e
    emu.addMemoryCallback(function()
      e.n = e.n + 1
      if e.n == 1 then e.first, e.scene0 = emu.getState()["frameCount"], kit.r16(0x0644) end
      local sc = kit.r16(0x0644)
      e.scenes[sc] = (e.scenes[sc] or 0) + 1
    end, emu.callbackType.exec, off, off, emu.cpuType.snes, emu.memType.snesPrgRom)
  end

  -- probes: { name = {off = <ROM offset of the instruction>, addr = <WRAM offset>, size = 1|2, dp = true: addr is a direct-page offset (D + addr)} }
  for name, p in pairs(opts.probes or {}) do
    local e = { n = 0, off = p.off, addr = p.addr, size = p.size or 1, dp = p.dp, vals = {}, nv = 0, scenes = {} }
    self.probes[name] = e
    emu.addMemoryCallback(function()
      e.n = e.n + 1
      local ea = e.addr
      if e.dp then ea = ea + (emu.getState()["cpu.d"] or 0) end
      local v = (e.size == 2) and kit.r16(ea) or kit.r8(ea)
      local sc = kit.r16(0x0644)
      local vk = string.format("%d@%02X", v, sc)
      if e.vals[vk] or e.nv < 24 then
        if not e.vals[vk] then e.nv = e.nv + 1 end
        e.vals[vk] = (e.vals[vk] or 0) + 1
      end
      e.scenes[sc] = (e.scenes[sc] or 0) + 1
    end, emu.callbackType.exec, p.off, p.off, emu.cpuType.snes, emu.memType.snesPrgRom)
  end

  if opts.control ~= false then
    emu.addMemoryCallback(function(a) if (a & 0xFFFF) == 0x36 then self.ctl36 = self.ctl36 + 1 end end,
      emu.callbackType.write, 0x36, 0x36, emu.cpuType.snes, WR)
  end
  if opts.nmi then
    emu.addMemoryCallback(function() self.nmi = self.nmi + 1 end, emu.callbackType.exec, opts.nmi, opts.nmi, emu.cpuType.snes, emu.memType.snesPrgRom)
  end

  local function pl(map)   -- {{key, count}, ...} sorted by key (a JSON array: integer-keyed maps do not serialise)
    local list = {}
    for k, c in pairs(map or {}) do list[#list + 1] = { k, c } end
    table.sort(list, function(x, y) return tostring(x[1]) < tostring(y[1]) end)
    return list
  end
  local function plnum(map)
    local list = {}
    for k, c in pairs(map or {}) do list[#list + 1] = { k, c } end
    table.sort(list, function(x, y) return x[1] < y[1] end)
    return list
  end

  function self.rows()
    local rows, prs, ex, pr = {}, {}, {}, {}
    for key, e in pairs(self.keys) do
      rows[#rows + 1] = { key = key, name = e.name, kind = e.kind, pc = e.pc, n = e.n, first = e.first, last = e.last or e.first, sc0 = e.scene0,
                          scenes = plnum(e.scenes), addrs = plnum(e.addrs), vals = plnum(e.vals), ctx = pl(e.ctx) }
    end
    table.sort(rows, function(x, y) return x.key < y.key end)
    for _, p in pairs(self.pairsT) do
      prs[#prs + 1] = { key = p.key, n = p.n, first = p.first, last = p.last or p.first, sc0 = p.scene0, addrs = plnum(p.addrs) }
    end
    table.sort(prs, function(x, y) return x.key < y.key end)
    for name, e in pairs(self.execs) do
      ex[#ex + 1] = { name = name, off = e.off, n = e.n, first = e.first, sc0 = e.scene0, scenes = plnum(e.scenes) }
    end
    table.sort(ex, function(x, y) return x.name < y.name end)
    for name, e in pairs(self.probes) do
      pr[#pr + 1] = { name = name, off = e.off, addr = e.addr, size = e.size, n = e.n, vals = pl(e.vals), scenes = plnum(e.scenes) }
    end
    table.sort(pr, function(x, y) return x.name < y.name end)
    return { rows = rows, pairs = prs, execs = ex, probes = pr, control36Writes = self.ctl36, nmiExecs = self.nmi, frames = self.frames, hits = self.hits,
             sceneFrames = plnum(self.scenes), sceneSeq = self.sceneSeq }
  end

  kit.onFrame(function()
    self.frames = self.frames + 1
    local sc = kit.r16(0x0644)
    self.scenes[sc] = (self.scenes[sc] or 0) + 1
    if sc ~= lastScene then
      lastScene = sc
      if #self.sceneSeq < 80 then self.sceneSeq[#self.sceneSeq + 1] = string.format("f%d:%02X", emu.getState()["frameCount"], sc) end
    end
    if opts.publishEvery and self.frames % opts.publishEvery == 0 then emu.mcp.result(self.rows()) end
  end)

  return self
end
```

## Positive control

Write watch on `$36` (the `INC $36` of the NMI handler, 80:8381) and exec callback on the NMI control offset 33528 (80:82F8), in every run: 76,662 `$36` writes against 76,658 NMI executions over the 46 main runs (per run the two differ by at most 1: `boot_power` 439/438, `chest_1D` 900/899, `chest_0E` 700/699, `n01_bot` 1461/1460, the other 42 equal). The natural replay alone: 18,847 / 18,847. Both mechanisms fire together with the game's frame counter, so callbacks, PC mapping (callback PC = address after the accessing instruction, mapped to the instruction that ends there) and frame counting work for this ROM. A second control inside the census: each watched byte that has a known writer (`$06A0` at `InitSystemVariables+54`, `$06C6-$06CD` zeroing in `ClearSceneState`, `$06F2` at `SpcMusicLoadCmd+3`) was seen from that writer.

Cold boot control (`boot_power`, 700 frames): the boot writers show the PCs the static prelude predicts: `$06A0` at 82:9E7D (`InitSystemVariables+54`, frame 3), the stub bytes `$0402-$0405` at 82:9E7D (`$0402` = `8B`, the `PHB` opcode) and 82:8E4B / 82:8E50 (frame 23, `$0405` = `DE`, `$0404` = `7F`). Callbacks at frame 0 attributed to PCs that cannot access the byte (82:9F30, the cold-boot WRAM clear) are classed "DMA/HDMA-attributed" in the tables and are not counted as writers.

Bit-change variant (flag bytes): `06EF bit4(0x10)` (write, records only a write that changes bit 4 of `$06EF`) and `0A1F bit7 change` (write, records only a change of bit 7 of `$0A1F`, flag `$FF`). Mask variant (follow-up runs): read watch on `$0A1F` that logs the accumulator at the read (`TestEventFlag` is entered with `A` = bit mask, `$80` = flag `$FF`) and the actor `D` and entry word.
