## 2. Per item

### B5a: layer and dual-layer scenes

**BA-03 (VERIFIED-RUNTIME).** One collision layer at `$7F:C000` (WRAM offset `0x1C000`), 256-byte pages of 16 x 16 cells, stride `$0693`. `RebuildCollisionLayer` runs `FillCollisionFromLayer0` (flag table `$06AA`, tile map base `$069E`) and, when `$06EF` bit 0 is set, `OverlayCollisionFromLayer1` (flag table `$06AC`, base `$06A0`); a nonzero layer-1 flag replaces the layer-0 flag. The Mu scenes pick their layer-1 water map from event flags (flag n = byte `0x0A00 + (n >> 3)`, bit `n & 7`); flag `$7E` set = drained. State `orig_S14h_mu62-drained.mss` (scene `$62`, flag `$7E` set) gives the drained map. Raw: `states_S14h_*.json`, `screenshots/B5_s62_spawn.png`.

**BA-02 (VERIFIED-RUNTIME).** All 9 dual-layer scenes `$0B $30 $5F $60 $61 $62 $64 $65 $67` give 0 mismatches against `expected = f1 != 0 ? f1 : f0` cell by cell; controls `$01` and `$15` give 0 (one load per scene, the check is deterministic). Raw: `ba02_overlay_*.json`. The B1 mismatch counts therefore covered layer-0 only.

**BA-01 (VERIFIED-RUNTIME).** Write watch over `$7F:C000-$FFFF` from the scene-change poke. `FillCollisionFromLayer0` (`$82:905B`) writes the whole layer once in every scene; only scenes `$55`, `$6B`, `$78`, `$D6`, `$D7` are rewritten afterwards, by:

| Writer | K:PC | Scene |
|--------|------|-------|
| `MarkCollisionRect`, `ClearCollisionRect`, `ClearCollisionRectFull` | `80:B303`, `B3B1`, `B3FD` | `$55 $6B $78 $D6` |
| `MarkSolidAbs`, `ClearTypeAbs` | `80:891C`, `89A3` | `$D6` |
| `av6C_portrait3` code, 4 single writes | `06:D750`, `D754`, `D758`, `D75C` | `$6B` |
| `CollisionLayerRenderer` (17,472 writes, frames 215-233) | `09:BBB1` | `$D7` |

Controls `$01` (ongoing `MarkCollisionRect` writes, frames 21-498), `$62`, `$15`. So the B1 mismatching cells are cells marked or cleared by COP collision ops and actor code, not a second map. Raw: `ba01_layer_writers_*.json` (its `snapDiff` field is meaningless: the snapshot precedes the load; use the histogram).

**BA-33 (settled by the code plus BA-03).** `BranchIfBehindWall` (`cop_handlers_actor_flags.asm`) reads the single merged layer; the layer-aware bit (actor byte `$0F` bit 4) selects a path in which both outcomes lead to "visible", so only the out-of-map test occludes. No layer index is read, so a dual-layer scene cannot change it. No runtime test run.
