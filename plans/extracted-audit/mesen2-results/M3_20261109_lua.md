# M3 Lua scripts (2026-11-09)

Companion of [M3_20261109.md](M3_20261109.md). All runs: `run_script` through the `user-mesen2-mcp-dev` namespace, `turbo: true`, ROM O, each run preceded by its own `load_state_file` (T-51 / T-66). The harness is `kit/lib/m3_kit.lua` (created in this step); `gaia.hold` / `gaia.release` come from `kit/lib/gaia_kit.lua`. Every run ends through `kit.finish` and writes the `raw/` file named in `out`.

## The harness (`kit/lib/m3_kit.lua`)

`m3.run{ cases = {...}, maxN = 2600, out = "M3_x.txt" }` loads the route table (ROM 241015) and the scene-name table at script load, then runs the cases one after another from the loaded state. It takes a savestate and restores it for each case in the exec callback of the NMI vector stub (ROM 32779); the case clock `n` counts NMI-stub executions since the load. Case kinds:

- `menu` (`choice`, `pos`, `rows`, `btn` = `a`|`b`|`y`, `afterA`, `maxN`): stages the same stores as `StageWorldMapChoice`, waits for the arrival at `$FE`, then presses right/down from arrival+300 and A/B/Y at the computed frame.
- `route` (`route`, optional `dest`, `scroll`, `origin`, `party`, `stop` = `landing`, `maxN`): stages the stores of `StageWorldMapMove` / `QueueMapChange` for the scripted trips (the 13 NPC scripts' party array, destination and scroll words are in `m3.SCRIPT`).
- Hooks: step loop {238913}, apply {238982}, end handler {239102}, truly-end {239115}, skip {239067}, landing {239172}, `WaitByte #0F` {238484} and `#3B` {239146} (call and resume), `LookupMapName` {239250} (found {239277}, miss {239286}, with the key byte at WRAM `$0000`), write callbacks on `$0D52-$0D6F` (`$0D58` and `$0D5A` lists, new `$0D5C-$0D5F` list) and on `$0642-$0643`, an exec range callback on {242689}-{244449} (the 27 dead `RestoreSavedPtr` offsets are in `m3.DEAD`), progress marks (`m3.extraMarks` adds more), an input callback, and a stall watchdog (no NMI for 240 frames after the arrival ends the run and says which case stalled).
- `m3.OFF`, `m3.EXIT` (choice id to start X, Y and origin scene), `m3.SCRIPT`, `m3.MENU` (25 menu trips with the expected route) are the data tables at the top of the file.

Changes made late in this step: `m3.extraMarks` (extra exec marks by name), the `$0D5C-$0D5F` write list and its print line.

## Preservation gap (stated, not hidden)

The Lua of the early pilots is not reproduced: `raw/M3_pilot.txt` to `raw/M3_pilot8.txt` and `raw/M3_cancel_t.txt` came from earlier versions of the harness (single-case diagnosis runs while the staging and the `$24` / `$2C` actor-relative reads were being fixed). The census runs below used the final harness except `M3_menu_*` and `M3_script_*`, which used the harness version before `m3.extraMarks` and the `$0D5C` print line were added (the other hooks are unchanged; the `$0D5C` result has its own run, `M3_w5c_1`).

## M3_castle_1.txt (Edward's Castle approach, state `orig_N03_castle_gate.mss`)

```lua
local rows, cmp, beq, ts = {}, {}, {}, {}
local PRG = emu.memType.snesPrgRom
local CPU = emu.cpuType.snes
local sc0 = kit.r16(gaia.addr.sceneCur)
local done = false
local first = {x=kit.r16(gaia.addr.playerX), y=kit.r16(gaia.addr.playerY)}
emu.addMemoryCallback(function(a)
  local st = emu.getState()
  cmp[#cmp+1] = string.format('f=%d A=%04X Y=%04X', st['frameCount'], st['cpu.a'], kit.r16(gaia.addr.playerY))
end, emu.callbackType.exec, 51988, 51988, CPU, PRG)
emu.addMemoryCallback(function(a)
  local st = emu.getState()
  beq[#beq+1] = string.format('f=%d Z=%d', st['frameCount'], (st['cpu.ps'] >> 1) & 1)
end, emu.callbackType.exec, 51991, 51991, CPU, PRG)
emu.addMemoryCallback(function(a)
  local st = emu.getState()
  ts[#ts+1] = string.format('f=%d staged', st['frameCount'])
end, emu.callbackType.exec, 51994, 51994, CPU, PRG)
gaia.hold({'down'})
local nf = 0
emu.addEventCallback(function()
  nf = nf + 1
  local p = gaia.player()
  rows[#rows+1] = string.format('%d:%04X,%04X,s%d,%04X,%04X', nf, p.y, p.x, p.scene, p.flags10 & 0xFFFF, p.mask & 0xFFFF)
  if p.scene ~= sc0 or nf >= 200 then
    if not done then done = true
      emu.mcp.writeFile('M3_castle_1.txt', 'start x,y=' .. string.format('%04X,%04X', first.x, first.y) .. ' scene0=' .. sc0 .. '\nCMP execs=' .. #cmp .. '\n' .. table.concat(cmp, '\n') .. '\nBEQ\n' .. table.concat(beq, '\n') .. '\nstage\n' .. table.concat(ts, '\n') .. '\nPER-FRAME n:Y,X,scene,flags10,mask\n' .. table.concat(rows, '\n') .. '\n', false)
      gaia.release()
      kit.finish({ frames = nf, cmp = #cmp, beq = #beq, staged = #ts, y_last = rows[#rows], first = rows[1] })
    end
  end
end, emu.eventType.endFrame)
```

(`gaia.addr.playerY` is the actor position; the `CMP` hook logs `A` = `playerYPos` `$09A4`, which is 16 less than the actor Y.) `M3_castle_2.txt` is the same script with `kit.w16(gaia.addr.playerY, y0 + 1)` before the hold and only the `CMP` hook.

## M3_exit_effects.txt (state `orig_N03_castle_gate.mss`)

```lua
local WR, CPU = emu.memType.snesWorkRam, emu.cpuType.snes
local seen, order, nf = {}, {}, 0
local sc0 = kit.r16(gaia.addr.sceneCur)
local OLD60 = kit.r16(0x0D60)
local OLD64A = kit.r16(0x064A)
kit.w16(0x0D60, 0x0002)
local function note(kind, tag, addr, value)
  local st = emu.getState()
  local key = kind .. tag .. string.format('%02X:%04X', st['cpu.k'], st['cpu.pc'])
  local s = seen[key]
  if not s then s = {kind=kind, tag=tag, k=st['cpu.k'], pc=st['cpu.pc'], first=nf, n=0, vals={}}; seen[key] = s; order[#order+1] = key end
  s.n = s.n + 1
  if kind == 'W' and #s.vals < 6 then s.vals[#s.vals+1] = string.format('%02X@%d', value & 0xFF, nf) end
end
emu.addMemoryCallback(function(a, v) note('W', '0D60', a, v) end, emu.callbackType.write, 0x0D60, 0x0D6B, CPU, WR)
emu.addMemoryCallback(function(a, v) note('R', '0D60', a, v) end, emu.callbackType.read, 0x0D60, 0x0D6B, CPU, WR)
emu.addMemoryCallback(function(a, v) note('W', '064A', a, v) end, emu.callbackType.write, 0x064A, 0x064B, CPU, WR)
emu.addMemoryCallback(function(a, v) note('R', '064A', a, v) end, emu.callbackType.read, 0x064A, 0x064B, CPU, WR)
gaia.hold({'down'})
-- an endFrame callback counts frames, releases Down at the arrival in scene $FE, and after 450 more frames
-- writes the lines (old/new values, then one line per (kind, tag, pc): first frame, count, values) through emu.mcp.writeFile
```

## Positive controls

Every `m3.run` file ends with `CTL nmi=... w36=... errs=0`; `w36` is the `INC $36` count, `nmi` the NMI-stub count. The hook range for the dead `RestoreSavedPtr` reports `options-code PCs reached: N distinct`; N was 4-5 in every menu case (the hook is live), 0-2 where no menu opened.
