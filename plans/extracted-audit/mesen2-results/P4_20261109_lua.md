# P4 Lua (calls)

All runs: ROM O loaded, `load_state_file` (the state named per section, `romCheck: match` checked), then `run_script` with `turbo: true` and `includes` `["mesen_kit", "iog_kit", "gaia_kit", "p4_kit", <run kit>]` (`a_actors` added for runs that look up live actors). The Lua of the driver and of every run is in `kit/lib/` (verbatim, nothing pasted twice):

| File | Role |
|---|---|
| `p4_kit.lua` | driver `p4.run{frames, out, setup, sched, tick, marks, rowfmt, from, to, collect}`: `$36` positive control, per-frame sampler (camera target and expected value from the controller formula, scroll, PPU scroll, cameraDeltaX/Y, effectDelta, playerFlags, entry), exec marks, chunked `emu.mcp.writeFile`, the final result table |
| `p4_ledge.lua` | `p4ledge.go{btn, out, frames, pressFrom, pressTo, clearCombatLock, freezeAtLand}`: Freedan ledge jump, Down to start, then the attack button; marks on `CheckLedgeJumpAttack`, `LedgeJumpDropAttack`, `LedgeJumpDropLand`, `CameraShakeActor`, `CameraShakeFrame`, the controller stores and `BranchIfPressed` |
| `p4_walk.lua` | `p4walk.go{out, frames, segs, rows}`: walks the player and records actor position minus layer-1 scroll on frames where the target is not clamped |
| `p4_drift.lua` | `p4drift.go{...}`: `camera_drift` marks (Simple, Ship, Patterned, `$24` reads, the pending store), `Layer1ParallaxRatio` marks, scene / teleport / enemy-approach options |
| `p4_bit12.lua` | `p4b12.go{out, frames, filter, hold}`: `$12` bit 12 test (optionally sets `displayModeFlags` bit 7) |
| `p4_ratio.lua` | `p4ratio.go{out, scenes, settle, sample, frames}`: logs the `MulDivide` arguments of `ComputeScrollDeltas` per scene |

> Provenance: the `run_script` argument strings were typed inline in the session and are not stored by the server or in the transcript. Only the calls below were copied back after the fact (the walk reruns of section 3 were run again at the end of the step, because the aggregate table of the first runs was returned in the reply and not written to the raw file). For every other raw file the kit file and the raw file are the verbatim record; the scene, hold buttons and teleport targets of the drift and ratio runs are visible in their raw rows (`sc=`, `pl=`), and the exact `frames` / `segs` arguments are not recoverable. If a description here disagrees with a raw file, the raw file is right.
