Ids (step): OQ-I023-1, OQ-I030-4, OQ-I036-1, OQ-I036-2, OQ-I036-3, OQ-I040-1, OQ-I040-2.

Conventions: every ROM offset is decimal (hook sites are decimal keys of `db-us/names/bank00.json`, `$82:XXXX` = file offset `0x20000 + XXXX`). "frame n" = the state after n completed frames of the case (the hook rows carry the same n; a hook row with n belongs to the frame whose end state is row n + 1). "Slot" = an actor slot, X = D = `0x1000 + 0x30 * k` (the player is `$1000`). "Cell (tx, ty)" = collision-layer cell; the player's cell row is `(actor Y - 16) / 16`, the actor X cell is `actor X / 16`. Arrival speeds in the ramp sweeps are forced: `place` writes the actor X/Y, zeroes `$09B2`/`$09B4`/`$09C6` and clears `playerFlags` bit `$1000`; then the speed word is poked and the direction key is held (stated per table). Natural approaches (no poke) are marked "natural".

## Method

`harness/scenario_b4.py --suite NAME --repeat 2` (every case runs twice in the same loaded state; the harness aborts when the two runs differ; all 13 final suite runs exited 0). One case = one `run_script` (`TRIAL`, below): load the state, optional geometry (`clear`, `paint` through `gaia.coll.set`), `place` (actor X/Y written, speeds and `$09C6` zeroed, `playerFlags` bit `$1000` cleared) and `pokes`, then `b4.run` (kit `b4_kit.lua`): exec hooks by ROM offset with a slot filter (X register = actor slot), write watches with PC, per-frame word columns, scripted D-pad input. The ramp slots, booster slot and glide trigger slots are found by `SCAN` (actor entry words `$D2D5` east ramp, `$D34D` west, `$D3BF` north, `$D42D` south, `$C966` booster; slot flag byte `$80`). `CELLS` dumps collision cells. Raw files: `raw/B4/<suite>_O_20261030.json` (the `*_only_*.json` files are single-case reruns kept as evidence; the full-suite files are the ones counted). Final-run logs: `raw/B4/logs/final_*.txt`.

Buttons: only the D-pad (`left`/`right`/`up`/`down` through `gaia.hold`, the logical and physical direction bits are the same) and, for the glide, the Psycho Slider slide: logical attack bit `$8000` = physical B on the vanilla ROM (the case holds `b` for 2 frames after the direction; `abilityBitmask` `$0AA2` is set to include bit 2 by a poke). "Run" = the direction, 2 frames, release 3 frames, hold (double tap). All waits are plain frame counts.

### Positive control (every run)

Writes to `$36` (`INC $36` in the NMI handler) are counted from the first frame of every case: **340 of 340** cases of the 13 counted suites have `ctl36 >= frames` (`controlOk` true; counts: `sweep` 192, `nsa1` 32, `gnorth` 24, `gsweep` 34, `itoryw` 16, `nsclear` 16, `booster` 7, `i030` 5, `ns` 4, `anim` 4, `wspeed` 3, `wprobe` 2, `itory` 1). The NMI exec control (`o2`-site 33528) was not hooked: the `$36` write counts equal the frame counts.

`kit/lib/b4_kit.lua` (the trial runner, verbatim):

```lua
-- description: B4 trial runner: exec hooks by ROM offset with an actor-slot filter and per-hook word columns, write watches with PC, per-frame word columns, scripted input.
-- requires: gaia_kit, b3_kit
--
-- All hook offsets are ROM FILE offsets of the ORIGINAL ROM (decimal keys of db-us/names/bankNN.json; a local label is bank << 16 + address).
--
--   b4.run{ frames=N, input=b3.schedule(segs), setup=fn, final=fn,
--           hooks = { {name=, off=, slot=<X register value or nil>, cols={ addr | {addr, true(signed)} , ... }} , ... },
--           cols  = { addr | {addr, true} , ... }                 -- per-frame columns (read after the frame's NMI)
--           watches = { {name=, lo=, hi=, kind="write"|"read", cols=...}, ... },
--           maxEvents = 1500 }
--   Hook event row : { n, name, xReg, <cols...> }          n = completed frames when the hook ran (the event belongs to the frame whose end state is row n + 1)
--   Watch event row: { n, name, addr, value, pc, <cols...> } pc = address AFTER the accessing instruction
--   Frame row      : { n, <cols...> }
--   Result         : { frames = {...}, events = {...}, ctl36 = <writes of $36 seen>, truncated = bool, final = ... }
-- addr is a WRAM offset (16-bit read; $7F:xxxx = 0x10000 + xxxx). Word reads: kit.r16.
b4 = b4 or {}
local PRG = emu.memType.snesPrgRom
local WR = emu.memType.snesWorkRam

local function readcols(cols, row)
  for _, c in ipairs(cols or {}) do
    if type(c) == "table" then row[#row + 1] = kit.r16(c[1], nil, c[2]) else row[#row + 1] = kit.r16(c) end
  end
end

function b4.run(o)
  local events, frames = {}, {}
  local n, started, handle, ctl36 = 0, false, nil, 0
  local cap = o.maxEvents or 1500
  emu.addMemoryCallback(function(a, v) if (a & 0xFFFF) == 0x36 then ctl36 = ctl36 + 1 end end,
    emu.callbackType.write, 0x36, 0x36, emu.cpuType.snes, WR)
  for _, h in ipairs(o.hooks or {}) do
    emu.addMemoryCallback(function()
      if not started or #events >= cap then return end
      local x = emu.getState()["cpu.x"]
      if h.slot and x ~= h.slot then return end
      local row = { n, h.name, x }
      readcols(h.cols, row)
      events[#events + 1] = row
    end, emu.callbackType.exec, h.off, h.off, emu.cpuType.snes, PRG)
  end
  for _, w in ipairs(o.watches or {}) do
    emu.addMemoryCallback(function(a, v)
      if not started or #events >= cap then return end
      local st = emu.getState()
      local row = { n, w.name, a & 0xFFFF, v, st["cpu.pc"] }
      readcols(w.cols, row)
      events[#events + 1] = row
    end, emu.callbackType[w.kind or "write"], w.lo, w.hi, emu.cpuType.snes, WR)
  end
  emu.addEventCallback(function()
    if not started then return end
    local b = o.input and o.input(n + 1) or nil
    local t = {}
    for _, name in ipairs(b or {}) do t[name] = true end
    emu.setInput(t, 0)
  end, emu.eventType.inputPolled)
  handle = kit.onFrame(function()
    if not started then
      started = true
      if o.setup then o.setup() end
      return
    end
    n = n + 1
    local row = { n }
    readcols(o.cols, row)
    frames[#frames + 1] = row
    if o.each then o.each(n, row) end
    if n >= o.frames then
      kit.off(handle)
      local res = { frames = frames, events = events, ctl36 = ctl36, truncated = (#events >= cap) }
      if o.final then res.final = o.final() end
      kit.finish(res)
    end
  end)
end
```
