## Scope: patched versus vanilla code

`extracted/` and its notes describe the vanilla ROM. The shipped build replaces several functions under test (`baserom/patches/MusicTransitions.patch.asm`, `APUWaitFixes.patch.asm`). Each verdict says which build it holds for. In the shipped build without MSU hardware (`$0D73 = 0`):

| Function | Vanilla (O) | Shipped (R-b2) |
|---|---|---|
| `SpcFadeOutHandshake` | `$F1`, wait echo, `$01`, wait 0 | same sequence (`cop_fade_normal`; `COP [C2]` = SetEntryHereAndYield) |
| `SpcTransferMusicData` | `$F0`, poll 0, `$FF`, stage ID, wait `$FFFF`, `$01` | no port writes: stages the ID and waits for `$FFFF` (`bgm_load_wait`); the loader writes the `$01` |
| `SpcMusicLoadCmd` / `loc_028B91` | WaitFrames(26), `$F2` + WaitFrames(32) if `$0D72`, `$F0`, poll 0, WaitFrames(2), `$FF`, WaitFrames(2), transfer, WaitFrames(3), `$01`/`$00` | no `$F2`; returns when the BGM id equals `$0D72`; `bgm_halt`: WaitFrames(1), `$F0`, WaitFrames(3), `$FF`, WaitFrames(2), transfer, WaitFrames(3), `$01`/`$00`; no poll for 0 |
| `$F2` | sent by the loader | sent by `ExecuteSceneTransition`'s token: `count_check` writes `$F2` to APUIO0 when the fade-out brightness reaches 6 (`loc_03DAF2` at the end of the fade otherwise), only when `bgm_table[next]` differs from `bgm_table[current]` and neither is `$FF` |

## Static prelude
- `docs/audio/spc-disassembly.md`: command dispatch `$068B`, CmdFadeOut `$0619`, CmdStop `$0636`, CmdF2 `$067F`, `ProcessPortCommand` `$06C2` (`$01`: ASL to `$02` path at `$06CB`; resets `$30/$31/$0E` at `$06DF`), FadeEnd `$04DD` (calls CmdStop), resident loader `sub_0f89`, `SyncPort` `$0504`, `MusicTick` `$0738`. Commands `>= $F0` jump to the dispatch without updating `$08`; the others go through the edge compare `MOV Y,$08 / CMP Y,$00 / BEQ`.
- Shipped text under test: `hdma_dma_spc.asm:361-369` (`SpcFadeOutHandshake` note), `:382` (`$01` comment), `cop_handlers_audio.asm:3` and `:61`, `scene_script.asm:75`, `:1294`, `:1319`, `:1325`.
- Trigger: `extracted/sky_garden/garden_descent/sp58_red_eye.asm`: `LDA $0AA6 / CMP #$0002`, then `COP [WaitByte] ( #01 )` (2 ticks), then `COP [FadeThenStartMusic] ( #02 )`.
- Patches read: `MusicTransitions.patch.asm:370-480` (handshake and thinker hooks), `:530-680` (loader), `:70-110` and `:190-300` (`count_check`, `ExecuteSceneTransition`, token `$00E6`). `APUWaitFixes.patch.asm` replaces chunk-end waits in cutscene actors (it polls `$2000` or APUIO1 = `$FF`) and does not touch the fade or the loader.

## Positive control

- SPC `SyncPort` (`$0504`) fired 488, 479, 341, 467 times; the SPC `$F4` read and write callbacks fire on every command (see observations); the DSP write callback fired about 5,000 times per run (`dsp w EVOLL` 4,989 in run B).
