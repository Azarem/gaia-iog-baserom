- `rg -n "WOBJSEL|W12SEL" extracted/mu` found only `code_0AF53D` (WOBJSEL); `rg -n "code_0AF53D" extracted` finds the one spawn at {717306}. `scene_lifecycle` 83:DE02-DE1C (tags 253442-253468) clears the window registers at every scene load; `ConfigDisplay` 82:8A8A-8AA5 (tags 166538-166565) writes TM / TMW / TS / TSW / CGWSEL / CGADSUB (the CGWSEL write is at 82:8A9E).
- Decode of the window bytes against `corpus/nesdev/ppu-registers.md`: W12SEL bit 0 = BG1 window 1 invert, bit 1 = BG1 window 1 enable, bits 2-3 window 2, bits 4-7 BG2; WOBJSEL bits 1-0 = OBJ window 1 (bit 1 enable, bit 0 invert), bits 5-4 = colour window 1; CGWSEL bits 7-6 = force main screen black (2 = inside the colour window), bits 5-4 = prevent colour math (2 = inside the window area), bit 1 = sub screen as addend. A window with WH0 > WH1 is empty; inverted, an empty window covers the whole line. TMW / TSW bits switch the masking on per layer.
- HDMA binder: `$68` is the next channel bit (starts `$02`, `ResetHdmaState`), `$6A` the register block offset (starts `$10`). `SetupHdmaChannel_*` takes A = bank | (B-bus register << 8) and Y = the table; the `ADC #$10` has no `CLC`, so its carry is the carry left by `ASL $68`, which is set only when `$68` was `$80`, that is on the 7th bind of a frame (channel 7).
- Table bound in frame N takes effect in frame N+1 (written in the main loop, enabled in the NMI). Within one scanline the channels run in numeric order and the last write to a shared register wins.
