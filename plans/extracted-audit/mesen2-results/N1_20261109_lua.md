# N1 Lua (2026-11-09)

Companion to [N1_20261109.md](N1_20261109.md). Every `run_script` call used `includes ["gaia_kit", "m1_kit", "n1_kit", "n1_runs"]` and `turbo: true`. The two kit files written for this step are `kit/lib/n1_kit.lua` (live-actor list, per-slot recorder, teleport, face) and `kit/lib/n1_runs.lua` (`n1r.watcher`, `n1r.talk`); they are on disk and unchanged since the runs. Interact on ROM O is physical B (`$8000`), so `n1r.talk` pulses `b` (with `a` as the second pulse for dialogue paging).

 n1r.talk(m, s, 0, 24, 'up', 700, {btn='b', btn2='a', watch={maxHp=0x0ACA, hp=0x0ACE, def=0x0ADC, str=0x0ADE, heal=0x0B22, jewels=0x0AB0, flagsE=0x0A1C, flagsEword=0x0A1D}})

## Statue pull, `N1_statue3` (scene `$51` loaded with `kit.w16(0x0642, 0x0051)` and 300 frames, banner closed)

```lua
m1.run(function(m)
 m.wait(3)
 local N, Sx = 0x1360, 0x1390
 local function trial(tag, px, py, dir, btn)
  n1.teleport(px, py); m.wait(10)
  n1.face(dir, 4); m.wait(6)
  local x0, y0 = kit.r16(N+0x14), kit.r16(N+0x16)
  local x1, y1 = kit.r16(Sx+0x14), kit.r16(Sx+0x16)
  gaia.hold({btn})
  local moved = false
  for f = 1, 40 do m.wait(1); if kit.r16(N+0x14) ~= x0 or kit.r16(N+0x16) ~= y0 or kit.r16(Sx+0x14) ~= x1 or kit.r16(Sx+0x16) ~= y1 then moved = true; m.log('%s moved at f=%d north=(%d,%d) south=(%d,%d) a28=%04X player=(%d,%d) $656=%04X', tag, f, kit.r16(N+0x14), kit.r16(N+0x16), kit.r16(Sx+0x14), kit.r16(Sx+0x16), kit.r16(0x1028), kit.r16(0x1014), kit.r16(0x1016), kit.r16(0x656)); break end end
  gaia.release(); m.wait(20)
  m.log('%s: player=(%d,%d) a28=%04X moved=%s north=(%d,%d) south=(%d,%d)', tag, kit.r16(0x1014), kit.r16(0x1016), kit.r16(0x1028), tostring(moved), kit.r16(N+0x14), kit.r16(N+0x16), kit.r16(Sx+0x14), kit.r16(Sx+0x16))
 end
 trial('north-side R down', 776, 768, 'down', 'r')
 trial('west-side R right', 728, 816, 'right', 'r')
 trial('east-side L left', 824, 816, 'left', 'l')
 trial('north-side L down', 776, 752, 'down', 'l')
end, {out='N1_statue3.txt', maxFrames=700})
```

`N1_statue2` (player 48 px south of the south statue, R held) gave the first no-move result; `N1_facetab` read `FacingDirectionLookup` (ROM 258335) with `emu.read(258335 + i, emu.memType.snesPrgRom, false)` for i = 0..87.
