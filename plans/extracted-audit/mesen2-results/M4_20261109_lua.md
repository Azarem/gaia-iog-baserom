# M4 Lua scripts (2026-11-09)

Companion of [M4_20261109.md](M4_20261109.md). All runs: `run_script` through the `user-mesen2-mcp-dev` namespace, ROM O unless a heading says R, each run preceded by its own `load_state_file` (T-66) except where a heading says it continued the previous run. The harness is `kit/lib/m4_kit.lua` (created in this step, on top of `m1_kit` / `gaia_kit`): `m4.tile`, `m4.tileSum`, `m4.tileBytes`, `m4.tileBlank`, `m4.vramHash`, `m4.cg`, `m4.rgb`, `m4.bg3`, `m4.vramMap`, `m4.rowText`, `m4.rowHex`, `m4.snap`, `m4.luHook`. Every run through `m1.run` ends with `kit.finish`, writes the `raw/` file named in `out` and carries the `INC $36` write watch as `control36`.

**Preservation gap (stated, not hidden).** The scripts of the first runs of this step are not reproduced here: `M4_font_vram_O_s01_0xC000.bin` (VRAM dump of the BG3 font), `M4_drawbox_O.txt` (DrawBox operands and cursor), `M4_music_O.txt` (the first barrel-roast jingle timeline), `M4_dialog1_O.txt` and `M4_dialog2_O.txt` (the Will and Kara lines of the roast dialog) were written in the part of the session before a context summary and I no longer hold the script text. Their raw outputs are in `raw/` and are the evidence for the rows that cite them; re-running them is the first thing to do before the apply pass relies on those rows. Every script below is the text that ran.

## M4_glyph (dialog glyph pixel values; continued the paused roast dialog, no reload)

```lua
local n=0
kit.onFrame(function()

 if n<3 then return end
 local L={}
 local function add(s) L[#L+1]=s end
 add('fontHash '..m4.vramHash(0xC000,8192)..' scene='..string.format('%04X',kit.r16(0x644)))
 for _,t in ipairs({0x14A,0x15A,0x180,0x190,0x1A2,0x1B2,0x10E,0x12F,0x140}) do
```

## M4_tpl_0F_d (`raw/M4_tpl0F_d_O.txt`; state `orig_P04_before_diamond_mine.mss`; template `$0F`)

## M4_title4 (`raw/M4_title2_O.txt`; state `orig_S01r_south-cape-ready.mss`)

The two earlier runs of this script (`M4_title_O.txt`, overwritten by the longer run, then superseded) read every block one scene late: the next `sceneNext` write waited behind the banner of the previous scene, and the hook at {172386} read `$00` after the first `DialogStringRenderer` call had reused it. This version waits for the banner flag and reads the count in `A` at {172329}.

```lua
m1.run(function(m)

 emu.addMemoryCallback(function() cur.cursor=kit.r16(0x998) end, emu.callbackType.exec, 172386, 172386, CPU, P)
 m.log('H1 k=%02X scene=%04X', emu.getState()['cpu.k'], kit.r16(0x644))
 for _,sc in ipairs({0xC3,0x0D,0x01}) do
  cur={}
  local w=0
  while kit.r16(0x0642)~=0 and w<300 do m.wait(1); w=w+1 end
  kit.w16(0x0642, sc)
  local n=0
  repeat m.wait(1); n=n+1 until (kit.r16(0x644)==sc and kit.r16(0x642)==0) or n>900
  local b=0
  while kit.r8(0xB4)==0 and b<300 do m.wait(1); b=b+1 end
  m.wait(20)
  m.log('SCENE %02X arrived n=%d bannerWait=%d b4=%02X count(A at 172329)=%s cursorAtRender=%s hook f=%s now f=%d', sc, n, b, kit.r8(0xB4), tostring(cur.cnt), cur.cursor and string.format('%04X',cur.cursor) or 'nil', tostring(cur.f), m1.frame())
  for r=6,9 do m.log('  r%02d %s', r, m4.rowHex(m4.bg3, r, 5, 31)) end
  local k=0
  while kit.r8(0xB4)~=0 and k<140 do m.wait(1); k=k+1 end
  m.log('  b4 after %d idle frames = %02X', k, kit.r8(0xB4))
  if kit.r8(0xB4)~=0 then
   local p=0
```

## M4_bcd_ctl / M4_bcd_patch (`raw/M4_bcd_ctl_O.txt`, `raw/M4_bcd_patch_O.txt`; state `orig_M2_diary_seeded.mss`)

One script with `PATCH` set to `false` (control) and `true` (patch). The patch is a write of the count byte `05` into `snesPrgRom` at the three `[BCD:2,D9E]` operands (ROM 783589, 783628, 783667) of the disposable state; nothing is saved. The control run continued from a state that had already run the scan script `M4_bcd_scan` (`raw/M4_bcd_scan_O.txt`: the eight `C6 02 00 aa 0D` operands at 783564-783654, 5 frames of idle) and the patch run was loaded fresh.

```lua
m1.run(function(m)
 local PATCH=true   -- false in the control run
 local P=emu.memType.snesPrgRom
 local calls={}
 emu.addMemoryCallback(function() calls[#calls+1]=m1.frame() end, emu.callbackType.exec, 254867, 254867, emu.cpuType.snes, P)
 m.log('H1 k=%02X scene=%04X PATCH=%s', emu.getState()['cpu.k'], kit.r16(0x644), tostring(PATCH))
 if PATCH then
  for base=0x0BF4C3,0x0BF540 do
   if emu.read(base,P)==0xC6 and emu.read(base+3,P)==0x9E then emu.write(base+1,5,P); m.log('patched count at %d -> %d', base+1, emu.read(base+1,P)) end
  end
 end
 m.wait(5)
 gaia.hold({'down'},1); m.wait(5); gaia.release(); m.wait(10)
 gaia.hold({'a'},1); m.wait(5); gaia.release(); m.wait(150)
 m.log('PrintNumber entries=%d first=%s', #calls, tostring(calls[1]))
 for r=12,19 do m.log('r%02d %s', r, m4.rowHex(m4.bg3, r, 0, 23)) end
 m.log('WRAM D9E..DA1: %04X %04X', kit.r16(0xD9E), kit.r16(0xDA0))
end, {out='M4_bcd_patch_O.txt', maxFrames=600})
```
