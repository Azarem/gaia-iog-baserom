# P2 Lua (calls)

All runs: `load_rom` (O), `pause`, `load_state_file` (the state named per section, `romCheck: match` checked), then `run_script` with `includes` `["mesen_kit", "iog_kit", "gaia_kit", "p2_kit", <run kit>]`. The Lua of the driver and of every run is in `kit/lib/` (verbatim, nothing pasted twice): `p2_kit.lua` (driver `p2.run`), `p2_will.lua`, `p2_df.lua`, `p2_wall.lua`, `p2_lunge.lua`, `p2_auraitem.lua`. The `run_script` `frames` argument is the per-variant frame count times the number of variants plus a margin; the per-variant count is the `frames` argument shown below.

> Provenance: the `run_script` argument strings were typed inline in the session and are not stored by the server or in the transcript. The spec lists below were reconstructed from the kit files and from the variant order in each raw file (the `poke` / `PsychoDashMain` / `df16` lines name direction and level per variant), not copied from a saved command. The kit files and the raw files are the verbatim record; if a list below disagrees with a raw file, the raw file is right.

```lua

  {kind="pd", pd=0, dir="up"},   {kind="pd", pd=1, dir="up"},

  {kind="pd", pd=0, dir="right"},{kind="pd", pd=1, dir="right"},

```

`$0B16` = `pd` is set in `vsetup`; the trace block prints `pos`, `d` = displacement from the start, speeds, `$28`, `$10`, playerFlags and `$09E0` for t = 172..206.

## 2. Spin Dash, Psycho Slider: damage, `$0AC8`, record reads, end of the dash (OQ-I062-2, OQ-I061-1, OQ-I072-4), S10, `raw/P2_will.txt`, `P2_will_sd.txt`, `P2_will_anim.txt`

Watches in `p2_will.lua`: `body0AC8` (write, PC `80:A03E`), `anim1028ov` / `anim1028all` (writes of `$1028`), `form0AD4`, `recRead` (reads of ROM 121255-121303, `82:C345`, `82:C34E`, `82:C35D`).
