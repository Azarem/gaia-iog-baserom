## Method (patterns recorded in the raw log, one block per target)
- Offsets are decimal ROM offsets (HiROM: offset = (bank << 16) | (CPU address & $FFFF)). CPU address = `$(bank|80):low word`.
- p16 = little-endian word `lo hi` of the target address (the form of `&label`, `$&label`, `#$&label`, table words). p24 = `lo hi B` with B in { bank, bank|$40, bank|$80, bank|$C0 } (the form of `@label`, `$@label`, spawn operands, scene actor records, thinker records). Command: `rg -a -b -o --no-unicode "(?-u:\xLO\xHI[\xBB\xBB|40...])" "rebuilt/Illusion of Gaia.smc"`.
- Targets per actor: the actor-def header (block start; every actor pointer in scene_actors and `COP Spawn*` targets it) and the entry (header + 3). Controls: PlayerCharacterDef header (181132, bytes `8c c3 82`), camera_scroll_controller header (60141, bytes `ed ea 80`), consolestring_01E818, thinker_spawn_0CEA2F.
- Each hit is classified by `raw/R3_helpers/r3_cls16.py`: `asset` = inside a `db-us/files.json` entry (compressed graphics, music, maps); `insn` = inside a tagged instruction of `extracted/` (file:line printed); `straddle` = crosses an instruction boundary; `data` = elsewhere, with the `blocks.json` block and the nearest name. A 16-bit pointer is bank-relative, so a hit in another bank than the target's is the same low word in a different bank and is counted, not itemised (the header of the raw log says so).
- Range scans: for every actor, a 24-bit scan for any pointer into the whole block [start, end), because a spawn can target a label inside the block. For each diary routine a 16-bit scan of `entry-1` (RTS / PEA dispatch tables store target - 1). Both are in the raw log (`range` and `RTS-trick` blocks).
- Coverage of the search space: every byte of the 2 MiB ROM (all banks, all alignments, odd offsets included) for every pattern; `extracted/` (all `.asm`) and `baserom/` (all patches) by `rg`.

Script (verbatim): `raw/R3_helpers/r3_fn.sh` (functions `cand label offset`, `range24 label lo hi [16]`), `raw/R3_helpers/r3_rx.py`, `raw/R3_helpers/r3_cls16.py`. Example calls: `cand idle_sprite_display:hdr 589055`, `cand idle_sprite_display:entry 589058`, `range24 "idle_sprite_display range" 589055 589078`, `range24 "DiaryCursorNav_noref(entry-1)" 781317 781318 16`.

Positive control (same run):
- PlayerCharacterDef header 181132: 24-bit hits in scene_actors records (data) and spawn operands (insn), fired.
- camera_scroll_controller header 60141: 24-bit hits in the scene actor table, fired.
- consolestring_01E818 (referenced string next to the six tested ones): referenced, fired through its pointer table word.
- thinker_spawn_0CEA2F (the list next to 0CEA45): 15 table words in `scene_thinkers` (845693, 845697, 845699 ... 845723) hold its low word, fired. Same scan shape returns zero table words for 0CE8E6, 0CE9EA, 0CEA45.
