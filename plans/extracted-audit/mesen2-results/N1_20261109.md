- `actors/jeweler_gem.asm`: the 8-jewel tier prints `dialogstring_08D395` (page 1 "…your Life [N]Power will be raised.", page 2 "Your Strength is[N]raised by one.") and the code raises max HP.

- `actors/hidden_red_jewel.asm`: flag index `$0E + $80` on base `$0200` (scene `$01`: `$81`, byte `$0A50` bit 1); the actor never changes its sprite.
- `actors/interaction_handlers.asm` (`push_handler_solid`): mask `$0031`, player at least `$20` px away on the axis, facing test through `GetPlayerFacingDirection`, one tile (`$10`) toward the player; `FacingDirectionLookup` (ROM 258335) entries `$3B`, `$3C`, `$3D` read 1, 2, 3 (up, left, right).
- `functions/npc_wander_ai.asm`: stand sets `$08 = $78`; step is half the walk animation's frames in pixels.
- `functions/FlickerParentActor.asm` (ROM 51194): flips bit `$2000` of the parent's `$10` every tick; `sp5B_neil`, `sp5B_lance`, `sp5B_kara`, `sp5B_erik` spawn it with `SpawnAfterAbsFlags ( @FlickerParentActor, #0, #0, #$2800 )`.
- `edward_castle/ec0C_ribber.asm` (689245-689254): `LDA #$0001; STA $loopCounter, X` before the jump into `smooth_follow_child`, so the speed of this caller is 1 pixel per frame (static).
