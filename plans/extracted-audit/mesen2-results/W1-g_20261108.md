## Script

The census engine is a memory callback per watch, keys `"<watch> <read|write> <K:PC>"`, PC = the address AFTER the accessing instruction (the harness maps it to the instruction that ENDS there with the `; {n}` tags), counts, scenes, values and, for reads, the last writer seen on the same byte ("init" = none in this run). local function sceneNow() return kit.r16(0x0644) end
local function frameNow() return emu.getState()["frameCount"] end

local function newT() return { keys = {}, n = 0 } end
local function tally(T, key, extra)
  local sc, f = sceneNow(), frameNow()
  local e = T.keys[key]
  if not e then
    if T.n >= 400 then return end
    e = { n = 0, first = f, sc0 = sc, scenes = {} }
    if extra then for k, v in pairs(extra) do e[k] = v end end
    T.keys[key] = e
    T.n = T.n + 1
  end
  e.n = e.n + 1
  e.last = f
  e.scenes[sc] = (e.scenes[sc] or 0) + 1
end
local function dump(T)
  local out = {}
  for k, e in pairs(T.keys) do
    local sc = {}
    for s, c in pairs(e.scenes) do sc[#sc + 1] = { s, c } end
    table.sort(sc, function(a, b) return a[1] < b[1] end)
    out[#out + 1] = { key = k, n = e.n, first = e.first, last = e.last, sc0 = e.sc0, scenes = sc, info = e.info }
  end
  table.sort(out, function(a, b) return a.key < b.key end)
  return out
end

local function absdiff(a, b)

  if d > 0x8000 then d = 0x10000 - d end
  return d

## Observations

1. `CopyActorState` stores the spawner's slot in `$24` and 35 instructions in 16 routines read it afterwards (FlickerParentActor, SpawnDamageNumberEffect, the hit stagger controller, StatueRewardOrbitalSparkle, camera_drift, pyCE_tuts, sp5C_skuddle, ir29_castoth, sg4E_plasma_snake, pyDD_queen_spirit_attack, awB1_gorgon, mtA1_fire_sprite, aw_spirit_follower, sE8_dark_gaia, dm3D_flayzer, pr_text_placement_calc). The note "reader of the initial value unknown" (`notes/comments/bank00.json:1618`) is wrong, and the block note of FlickerParentActor already says the helper finds its parent there.
2. Scene `$FF` counterfactual (`g_ff_ctl` against `g_ff_patch`): 42 spawns in scene `$FF`; in the control the `BEQ` was taken 42 / 42 (clear not executed); with the `BEQ` removed the clear ran 42 / 42. Before the clear, in every one of the 42 spawns the new slot's extendedFlags and `$7F1000 / 1002 / 1004` callbacks and the spawner's are all 0 (`new ext=0000 hit=0000 dodge=0000 death=0000 | spawner ext=0000 hit=0000 death=0000`). The hit totals (9,028), the scene sequence and the end state of the two runs are identical. So skipping the clear changes nothing observable on the exercised path. The claim that the exception is for the overlay (shipped: "inferred") needs a case where the spawner or the slot holds a non-zero extendedFlags or callback at spawn in scene `$FF`, which no run produced.
3. Speeds: the dominant axis of the straight-line step equals the speed stored (1, 1, 2, 4 / 5 / 7). pyCC_blaster has two projectile actors with different speeds, 1 and 3. `$0B02` is 0 in normal play (one writer: the boot fill), so pyDD's speed is 4; with `$0B02` poked 1 and 3 it is 5 and 7. `$0B02` is added in the awB1_goldcap, mtA1_fire_sprite, pyDD (speed and timer `$08` = `$0168` + `$0B02` x 64) and cyclops (`$24` = `$0B02` + 4) code: a difficulty level (`docs/ram_map.txt:222`).
4. Escort tracker: the ring has 9 entries after setup (offsets `$00`-`$40`) and every access masks the head with `$3F`; no tracker instruction reads `$7EDF40-$7EDF7F`, so the ninth entry is written and never read. The region is not private to the tracker: scene decompression, tilemap fill, palette and credits code read and write `$7EDF00-$7EDF7F` (never in a scene with a tracker in these runs). The seed is the row index + 1: seed 4 selects delta-table row 3 (X -2: the trail runs west of the NPC) and fills the facing words with 2, so the NPC's first idle animation is `$1A` + 2; seed 3 selects row 2 (trail east, facing word 3, animation `$1D`). Seed 0 (use the player's facing) was not measured.
